# Privacy policy

IoT Offline Toolbox is a local-first diagnostic utility.

## Local data

The application may store on the current device:

- saved device names, addresses, ports, tags, and notes;
- endpoint profiles that exclude passwords and sensitive headers;
- payload templates;
- bounded activity logs and request/response previews;
- application settings and the last selected screen;
- redacted quarantine records when persisted JSON cannot be decoded;
- explicit JSON backups generated by the operator.

No analytics, advertising, telemetry, cloud account, or automatic synchronization SDK is included. Local inventory and history are not uploaded to an MSA service.

## Network traffic

Network traffic is initiated only after an operator starts an operation. Requests are sent directly to the endpoint entered or discovered by the operator. Browser builds remain subject to CORS and sandbox restrictions. iOS local-network access is declared in `Info.plist` and still requires operating-system permission.

Public cleartext HTTP/WS destinations are blocked by default. Local/private cleartext destinations are permitted with a warning because many embedded devices do not provide TLS.

## Credentials and payloads

MQTT passwords are held only for the current operation and are not written to endpoint profiles or backups. Common credential forms are masked before logs, history, quarantine metadata, and backups are persisted. Sensitive profile headers are removed.

Redaction cannot understand every proprietary payload format. Review payload templates, logs, and exported backups before sharing them.

## Backup, recovery, and deletion

Backups are generated only by an explicit operator action and are never uploaded automatically. Import is validated before writes and attempts rollback if a write fails. Corrupted records are quarantined locally so operators can see that recovery occurred without exposing the unredacted value.

Android Auto Backup is disabled. Clearing application data or uninstalling removes storage according to the host platform's application-data behavior.

## Operator responsibility

Use the toolbox only on authorized networks. Prefer encrypted transports whenever the target supports them and avoid entering production credentials into diagnostic payloads.
